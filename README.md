# AI-Driven Automated Video Generator

This project is an intelligent, end-to-end video generation platform that converts simple text prompts into fully rendered videos using the power of AI.

## 📌 Overview
The AI-Driven Automated Video Generator is designed to streamline the content creation process for educators, marketers, and content creators. It automates key stages of video production including:

- **Script Generation** using ChatGPT (OpenAI API)
- **Voiceover Synthesis** via EdgeTTS
- **Captioning** with Whisper (speech-to-text)
- **Video Assembly** using stock footage from the Pexels API and rendering via MoviePy & FFmpeg

All interactions are built using **Streamlit**, providing a smooth, stage-wise user interface from idea to final video output.

## 🚀 Features
- One-click video generation from a topic or idea
- AI-generated scripts, captions, and lifelike voiceovers
- Timed caption synchronization
- Video search and retrieval from stock libraries
- Simple, intuitive UI for non-technical users
- Customization options for script, voice, and video

## 🛠️ Technologies Used
- Python 3.11
- Streamlit
- OpenAI GPT (ChatGPT)
- EdgeTTS
- Whisper
- MoviePy
- FFmpeg
- Pexels API
